## 使用细节

- 16–24px 使用简化图形，32px 起使用主图形；简化版移除独立圆形节点并加粗相对线宽。不要直接把复杂组合缩到 favicon 尺寸。
- 横向组合建议最小宽度 165px；更窄位置仅用图形。保留 SVG 原始比例。
- 安全留白至少为图形画布高度的 1/8，例如 64px 图形周围保留 8px；横向组合也以图形高度计算。
- 禁止拉伸、旋转、额外描边和渐变。复杂背景先提供纯色底板。
- 用具体文件管理颜色，不依赖外部页面 CSS 修改作为图片嵌入的 SVG。
- 字标用于品牌展示，正文及可访问名称写作 Willcord；与文字重复的装饰图标使用空 alt，独立 Logo 使用 `alt="Willcord"`。

对比度按 sRGB 相对亮度公式计算：主紫／白为 4.56:1，淡紫／深底为 7.18:1，深墨／暖浅底为 13.78:1。主紫／白超过 4.5:1 但余量较小，正文优先深墨，不降低不透明度。以上数值仅适用于指定色对，不代表整个产品界面已经完成无障碍验收。
