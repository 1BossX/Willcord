# Research 与经验沉淀

外部调研、最佳实践和开发中得到的教训，供后续阶段设计与评审参考。这里的结论不自动成为需求；要落地的项须进入 [开发计划](../development-plan.md) 或 [架构方案](../architecture.md)。

## 约定

- 一个主题一个文件，文件名 `YYYY-MM-DD-<topic>.md`（日期为调研日期）。
- 每篇包含：来源（附链接与访问日期）、来源可信度/矛盾、值得学习、值得避免、对 Willcord 的映射与建议动作。
- 区分“来源原话/事实”和“我们的推断”；未核实的内容标明。
- 建议动作被采纳后，在条目后注明落到的阶段或 PR；被否决也写一句原因。
