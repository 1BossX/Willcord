# Public acceptance evidence

The public tree keeps login screenshots, isolated P1 demo states and redacted acceptance JSON. Screenshots containing infrastructure names, device fingerprints, execution output or local paths have been moved to the maintainer's ignored `.private-evidence/` directory.

Historical acceptance conclusions in the development documents are retained. Removing files from the current tree does **not** remove them from Git history. Review the history exposure decision in `docs/open-source-readiness.md` before making the repository public.

Fresh screenshots for public releases should use isolated demo data and be visually reviewed before committing or attaching them to a public release.
