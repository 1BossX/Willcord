01 / EXECUTION

断线先对账，
未知不重跑。

重新连接后先核对执行账本。无法证明命令是否执行过时，挂起等待人工核对，不盲目重试。

02 / MODEL KEYS

模型密钥，
集中在主节点。

模型调用与 Agent 规划都在主节点。执行机器不保存模型密钥，也不需要访问模型服务，只持有自己的设备身份与凭据。

03 / NETWORK

出站连接，
无需入站端口。

worker 通过出站 WSS 主动连接主节点，执行机器不必开放任何入站端口。

04 / DELEGATION

跨机器委派，
可取消、有预算。

Main Agent 查看各机器状态并委派任务。委派任务与用户任务共用队列，支持取消传播、超时和预算限制。

HOW IT WORKS

一个控制面，
连接你的执行现场。

主节点规划任务、管理会话和调度。
worker 在限定的工作目录中执行工具，并回传结果。

  1. 01

    主节点规划

    模型调用、Agent 循环、会话历史与调度都在主节点完成。

  2. 02

    worker 执行

    执行机器上的 worker 出站连接主节点，在工作目录中执行 read、write、bash，并负责取消与对账。

  3. 03

    结果可追溯

    每次调用都写入执行账本，并显示在任务时间线上；状态未知的调用交由人工核对。

GET STARTED

部署中心，连接机器，开始任务。

主节点用 Docker Compose 部署，提供 HTTPS 控制台；
worker 安装在每台执行机器的宿主机上。

流程：安装 willcord 命令 → 启动主节点 → 信任内部 CA → 登录控制台 → 启动 worker → 核对指纹并批准 → 等待“可执行” → 完成只读任务。先在每台机器上装命令（只安装，不启动任何服务），再用命令启动对应角色。安装器默认使用最新正式 Release 并校验 SHA-256；固定版本加 --version vX.Y.Z。

curl -fsSL https://bossoptional.github.io/Willcord/install.sh | bash

命令装到 ~/.local/bin，不改你的 shell 配置；目录不在 PATH 里时会打印一行 export PATH=…。装给所有用户用 bash -s -- --system。

01 / MAIN NODE

启动主节点

在 Linux x86_64/arm64 主机（macOS 可用 Docker Desktop 试用）上准备 Docker Compose v2，运行向导。向导只问访问地址（自动列出本机探测到的内网 IP 供选择）和管理员密码，启动服务并导出 ca.pem；模型不在安装时设置，登录控制台后在“模型连接”绑定 API key。

willcord main init

让浏览器信任这个根证书后登录控制台；执行机器不必提前复制它。镜像固定为命令对应的版本；之后在任意目录用 willcord main status、logs、upgrade 管理。

02 / WORKER

启动并授权机器

在已信任的控制台打开“机器授权 → 添加机器”，取得主节点地址和 CA 指纹。命令含 CA 指纹，核对根证书后才建立连接。

示例，指纹以控制台生成的为准：

willcord worker join 'https://plane.internal:8443' --ca-fingerprint '<控制台提供的64位指纹>'

个人电脑用普通账户运行；常驻服务器用 --system 装命令，再 sudo willcord worker join … --system --user 'ops'，指定已有的非 root 账户。控制台也提供一步完成的 install.sh worker …，等于安装命令后立即 join。随后在控制台核对节点 ID 与指纹并批准，等机器显示“可执行”。

03 / FIRST TASK

创建会话，检查结果

在工作台选择“可执行”的机器和默认工作目录，新建会话，输入“列出当前工作目录的文件，并报告工作目录路径”，检查回复与任务时间线。

已有项目用 willcord worker workspace add <ID> <绝对路径> 添加，再新建会话。跨机器协作使用 Main Agent 委派任务。

BEFORE YOU START

清楚的能力，
明确的前提。

不是 shell 沙箱。Bash 以 worker 服务账户的实际权限运行，工作目录限制不等于隔离。请为 worker 使用独立的最小权限账户。

单管理员设计。不要向不可信用户开放执行。文件内容、命令输出和会话可能进入模型上下文，采用前请确认模型服务的数据处理策略。

网络可达。执行机器必须能直接访问主节点；跨 NAT 中继尚未交付。

项目处于开发与受控验收阶段，用于生产前请在自己的环境完成安全、权限与故障恢复验收。详见安全策略。
